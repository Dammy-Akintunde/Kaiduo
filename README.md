# 🎬 Kaiduo

Kaiduo is a movie discovery platform that provides link access to watch and download movies and TV shows. 
*Note: Kaiduo does not host any media files; it only provides links.*

## ✨ Features
* Browse movies and TV shows
* Direct links for watching and downloading
